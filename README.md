# MyLinux Platform

An experimental, modular Android/Linux platform project.

MyLinux aims to provide developers with an understandable starting
point for exploring operating-system components, system services,
hardware abstraction, security, and platform development.

## Project status

MyLinux is under active development.

Some components are prototypes, incomplete implementations, or
experimental scaffolding. Do not assume full Android or AOSP
compatibility.

## Repository layout

- `system/`  Core system components and services
- `hardware/` Hardware abstraction and interfaces
- `frameworks/` Framework development
- `packages/` Platform packages and applications
- `device/` Device configurations
- `vendor/` Vendor-specific components
- `build/` Build infrastructure
- `tests/` Project tests
- `tools/` Developer utilities
- `docs/` Documentation
