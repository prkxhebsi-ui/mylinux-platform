# MyLinux Dalvik Public Headers

This directory contains public declarations and shared type definitions
for the MyLinux Dalvik runtime.

Contents:
- Runtime and VM interfaces
- Thread, class, method, field and object interfaces
- Heap and garbage collector interfaces
- DEX parsing and instruction interfaces
- Bytecode verification and interpreter interfaces
- JNI and native method declarations
- Reflection and debugging interfaces
- JDWP, properties and logging declarations

These are header declarations only.
They do not provide implementations or executable functionality.

Implementations belong in the corresponding source directories.
