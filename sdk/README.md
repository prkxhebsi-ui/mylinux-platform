# MyLinux SDK

The MyLinux SDK provides platform APIs, development tools, build metadata,
compatibility definitions, documentation, and test infrastructure.

## Compatibility areas

- aosp/: interfaces intended to follow the selected AOSP revision.
- mylinux/: MyLinux-specific extensions.
- compat/: adapters between the two.

## Important

Directory creation does not provide functional SDK binaries.
Build tools and platform artifacts must be supplied and validated separately.
