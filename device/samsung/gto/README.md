# MyLinux Samsung GTO

Device target: Samsung SM-T295
Device codename: gto
Architecture: arm64
Android base observed on device: Android 11

This directory contains the MyLinux device configuration for GTO.

Hardware configuration, proprietary blobs, kernel settings, init actions,
and SELinux rules must be verified before they are enabled in a build.

Do not replace shared AOSP files with device-specific files.
