# MyLinux Compatibility Test Suite

Project: MyLinux
Target: Android 11
API Level: 30
Architecture: ARM64

## Purpose

The MyLinux CTS checks compatibility of platform APIs,
permissions, packages, runtime behavior and security.

## Test categories

- API compatibility
- Framework behavior
- Package management
- Permission enforcement
- Security behavior
- Core Java library behavior
- Device information
- Host-side validation

## Test execution

Tests are divided into host-side and device-side groups.

Host-side tests run on the development computer.
Device-side tests run on a connected MyLinux device.

This is a custom test framework layout, not the official
Android Compatibility Test Suite.
