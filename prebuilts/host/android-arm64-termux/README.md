# Android ARM64 Termux Host

Primary MyLinux development host.

Expected tools:
- clang
- clang++
- ld.lld
- llvm-ar
- llvm-nm
- llvm-objcopy
- llvm-strip
- make
- ninja
- python3
- go

Initially these tools may be provided by Termux packages.
Do not copy incompatible Linux glibc executables into this directory.
