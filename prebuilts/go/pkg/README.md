# MyLinux Go Package Archives

Stores compiled Go package archives.

These are Go compiler artifacts, not C/C++
static libraries.

Host:
- linux_amd64

Target:
- android_arm64

Archives are generated by the Go compiler.
Do not create empty .a files.
Do not register these as Soong C/C++ libraries.

The archive format and package metadata must
match the selected Go compiler version.
