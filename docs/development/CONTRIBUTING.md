# Contributing to MyLinux

Thanks for your interest in MyLinux.

## Before contributing

- Read the architecture overview.
- Check whether the component is implemented or experimental.
- Check imported source licenses.
- Avoid unrelated changes.

## Code contributions

- Keep changes focused.
- Use clear names and comments.
- Handle errors explicitly.
- Document dependencies.
- Include tests where practical.

## Pull requests

Describe:

1. What changed?
2. Why was it needed?
3. How was it tested?
4. What limitations remain?

Do not claim a feature works unless you have tested it.
