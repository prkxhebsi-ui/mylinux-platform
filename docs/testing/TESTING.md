# Testing MyLinux

## Testing levels

1. Source inspection
2. Individual source compilation
3. Unit tests
4. Integration tests
5. Emulator or device tests
6. Boot and runtime validation

## Reporting results

For each test, record:

- Component
- Command
- Target architecture
- Expected result
- Actual result
- Pass or fail

A compiled object file does not prove that a component works
at runtime.
