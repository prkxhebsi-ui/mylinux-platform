# MyLinux 4S Battery Development

Nominal pack voltage: 14.4–14.8 V nominal

Developers may implement their own:
- Fuel-gauge interfaces
- Battery monitoring
- Protection-controller interfaces
- Hardware drivers
- Battery-management logic
- Tests and examples

Languages: C and C++.

Supported extensions:
.c .cpp .cxx .cc .h .hpp .hxx .hh

This directory is a software development scaffold, not a validated
battery circuit or charging design.
