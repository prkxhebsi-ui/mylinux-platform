MyLinux Luni Configuration

luni.conf:
  Java Properties runtime configuration.

luni.json:
  Structured Luni metadata.

mylinux.envs:
  Custom MyLinux environment descriptor.

Java loaders:
  LuniConfig
  LuniMetadata
  LuniEnvironment

Environment magic:
  0x18383989

Environment format:
  ENV1

JSON dependency:
  org.json from libcore/json.

All files are configuration and metadata.
The environment magic is an identifier, not a security signature.
