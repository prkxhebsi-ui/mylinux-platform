# MyLinux NDK

Native Development Kit for MyLinux.

Target:
- Architecture: arm64
- Android API: 30
- Target triple: aarch64-linux-android30

Components:
- Bionic: Android C library and linker
- libc++: C++ standard library
- libc++abi: C++ ABI
- compiler-rt: compiler runtime
- libunwind: stack unwinding
- kernel-uapi: Linux userspace kernel headers
- libandroid: Android native APIs
- liblog: Android logging API

Source and generated sysroot are maintained separately.
